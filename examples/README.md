# Configuration examples

[init.lua](https://github.com/komawm/koma/blob/main/examples/init.lua) is the annotated Koma configuration example. Compare it with the [Lua API specification](https://github.com/komawm/docs/blob/main/docs/LUA_API_SPEC.md) and [generated LuaLS definitions](https://github.com/komawm/koma-types/blob/main/types/koma.lua). Validate a copied configuration before using it with a running compositor.

[Jiku](https://github.com/komawm/jiku) is a separate repository with its own examples and an installable agent skill. The [CLI workflow sample](https://github.com/komawm/koma/blob/main/examples/coding-agent-cli.md) shows the shell-driven path for terminal coding agents; the installable skill lives at [`skills/koma-desktop/`](../skills/koma-desktop).
